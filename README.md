# Proyek Gradle - Custom Greeting Task

## Deskripsi Tugas
Proyek ini adalah proyek Gradle sederhana yang memiliki custom task bernama `greetingTask` di dalam `lib/build.gradle`. Task ini menerima parameter nama (`-Pname`) dan menampilkan pesan sapaan di terminal.

## Tujuan
- Memahami struktur dasar proyek Gradle.
- Belajar membuat dan menjalankan custom task di Gradle.
- Menggunakan parameter input (`-Pname`) pada task Gradle.

## Cara Menjalankan
```bash
./gradlew greetingTask -Pname=Maulida
```
